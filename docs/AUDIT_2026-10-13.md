## Source and methodology

Source existence, license and README snapshots were retrieved through connected GitHub access. Readback of the published RepoOrbit registry and all 26 static shards was performed against an independently reconstructed normalized reference map. README-line checks used the recorded source line, source blob SHA and canonical target URL. All 26 generated shard payloads matched the recomputed deterministic lexical tables exactly.

These structural checks cannot establish the correctness of arbitrary upstream claims, repository license compatibility, runtime functionality, end-user costs, security, semantic retrieval performance, or GitHub-wide coverage.
